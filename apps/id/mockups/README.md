# MoonWitness ID Mockups

## Concept 01 — The Lunar Identity Archive

- Asset: [moonwitness-id-concept.svg](./moonwitness-id-concept.svg)
- Art direction: LUNAR CHRONICLES
- Experience sequence: ARRIVAL → IDENTITY GATE → PERSONAL ORBIT → SESSION ARCHIVE
- Status: visual concept / proposed, not implemented UI.

## Design intent

MoonWitness ID should feel like a personal observatory and precision identity instrument: quiet, personal, measured, editorial, and unmistakably lunar. It is not a generic SaaS login template or an operations dashboard.

## Authority and implementation notes

- ARSY remains the authority for identity, authentication, sessions, tenant, roles, and authorization.
- The mockup is not evidence that passkeys, social login, session metadata, or any other depicted capability exists. The actual implementation must use only verified source and SDK contracts.
- Treat any detail not currently supported by source as illustrative placeholder content, not a feature requirement.
- Use the shared `@moonwitness/ui` components and `lunar-chronicles` skin; do not fork tokens or primitives.
