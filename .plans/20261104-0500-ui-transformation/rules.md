# Full UI Transformation Rules

1. Preserve business behavior, routes, SDK calls, authentication, tenant isolation, and existing work.
2. Keep one shared component and interaction engine under `@moonwitness/ui`.
3. Do not reduce skins to palette themes or copy proprietary interfaces.
4. Use only approved canon, existing assets, or placeholders explicitly labeled as placeholders.
5. Do not display unverified statistics, testimonials, status, progress, observations, users, or performance metrics.
6. Every control has a real behavior, accessible name, visible focus, hover, active, and disabled state where applicable.
7. Minimum targets are 44px. Reflow without horizontal scrolling.
8. Pauseable ambient motion stops under reduced motion and never communicates fabricated data.
9. Verify with production servers and hydrated browser sessions.
10. Record pass, fail, and blocked gates separately.
11. Update only documentation canonically affected by the change.
