# Full UI Transformation Design

## Design read

Reading this as an ecosystem transformation for operators, account owners, researchers, and creative audiences in six distinct cinematic worlds.

- ENERGY: shared shell actions stay 1-2.
- RHYTHM: Imperium and Lunar 2, Nexus 1-2, Mycelium 2-3, ROCKSOUL 2-3, RIOT ANARCHY 3.
- MOTION: Imperium 2, Lunar 1-2, Nexus 1, Mycelium 2, ROCKSOUL 2, RIOT ANARCHY 3.

## Transformation system

1. Establish route scores for hierarchy, identity, composition, density, states, responsiveness, keyboard operation, and visual craft.
2. Build the Laboratory around the same representative navigation, content, form, status, and empty-state task.
3. Transform Dock toward monumental threshold composition.
4. Transform Headquarter toward calm, dense operator instruments.
5. Transform ID toward readable lunar archive governance.
6. Transform WORLD OBSERVATORY toward provenance-first research composition.
7. Give ROCKSOUL an editorial narrative rhythm and RIOT ANARCHY controlled punk asymmetry.

## Visual decision record

- Skin-specific layouts exist because recoloring a shared dashboard would erase the approved DNA identities.
- Laboratory tasks are repeated because they make skin differences directly testable.
- Headquarter remains denser because operators need faster task scanning.
- WORLD OBSERVATORY stays provenance-first because its content depends on source trust.
- RIOT ANARCHY asymmetry remains bounded by predictable DOM order, keyboard flow, and touch-safe controls.
