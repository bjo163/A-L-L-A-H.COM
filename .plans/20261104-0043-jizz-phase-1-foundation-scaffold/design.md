# Design: JIZZ Phase 1 — Foundation & Next.js 16 Application Scaffolding

## Composition & Layout
- Global application shell wrapping all pages with `MoonFrameRoot` from `@moonwitness/ui/skins`.
- Default skin set to `lunar-chronicles` (Astronomical / Observatory theme) with seamless support for `imperium-lumen`, `rocksoul`, and other DNA skins.
- Responsive container with accessibility annotations and dark-mode default tokens.
