# Rules: MOONLAB Phase 1 — Research, Experimentation & AI Sandbox Foundation

## 1. Sandbox Invariants
1. **Isolated Quota Allocation**: Sandbox experiments run under isolated virtual keys with designated test budgets to prevent draining production tenant credits.
2. **Deterministic Evaluation**: Benchmark scoring must use verifiable assertion functions or semantic similarity thresholds ($\ge 0.85$).
3. **Tenant Isolation**: Mandatory `company_id` filter on all datasets, experiments, and benchmark outputs.
