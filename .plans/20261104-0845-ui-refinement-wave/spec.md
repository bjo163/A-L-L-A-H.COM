# Focused UI Refinement Wave

## Goal

Raise the visual quality and resilience of Dock, Headquarter, ID, and WORLD OBSERVATORY without changing product behavior or expanding scope into backend work.

## Scope

- Shared ecosystem navigation and skin recipes when app shells expose a defect.
- Dock entry and destination composition.
- Headquarter overview and operational routes.
- ID login, register, root, account, loading, error, and session states.
- WORLD OBSERVATORY entry and source-backed empty/error states.
- Responsive behavior, keyboard use, focus, contrast, and motion.

## Out of scope

- Skin Laboratory or new six-world routes.
- ROCKSOUL and RIOT ANARCHY runtime surfaces.
- Authentication, SDK, API, tenant, database, or routing behavior changes.
- New logos, avatars, statistics, testimonials, observations, or unapproved artwork.

## Acceptance criteria

- The baseline and final route evidence are recorded.
- Highest-impact visual defect clusters are resolved.
- Production hydration is verified for modified interactive controls.
- 320, 390, 768, 1024, and 1440 pixel checks have no horizontal overflow.
- Keyboard menu and form behavior pass where applicable.
- Focused UI tests, typecheck, and affected app builds pass.
- Remaining repository baseline failures are reported separately.
