# Focused UI Refinement Wave Rules

1. Preserve routes, authentication, SDK calls, API behavior, and tenant boundaries.
2. Use `@moonwitness/ui` for shared controls and existing app patterns for route-specific work.
3. Add no features, backend behavior, assets, claims, data, or routes beyond demonstrated UI defects.
4. Every control retains native semantics, an accessible name, visible focus, and real behavior.
5. Maintain truthful loading, empty, error, success, and offline states.
6. Reflow without horizontal scrolling and preserve 44px touch targets.
7. Stop decorative motion under reduced motion.
8. Verify production runtime behavior.
9. Preserve unrelated worktree changes and report baseline gates separately.
