# Focused UI Refinement Wave Design

## Design read

Reading the active ecosystem as four task-oriented surfaces with distinct cinematic identities:

- ENERGY 2 overall; Headquarter stays calmer at ENERGY 1-2.
- RHYTHM 2 across shared work.
- MOTION 1-2, with Nexus Paradox static unless feedback requires movement.

## Priority

1. Dock establishes the ecosystem threshold and destination hierarchy.
2. WORLD OBSERVATORY makes source trust and unavailable-data states explicit.
3. ID presents account and authentication tasks as one lunar identity system.
4. Headquarter clarifies task density without turning every route into another dashboard.

## Visual decisions

- Shared mobile navigation remains compact because ecosystem navigation is secondary to the current task.
- Headquarter keeps useful density for operators and uses labels and route hierarchy to preserve scanability.
- Account and observatory content use measured line length rather than repeated equal cards.
- One real-state accent marks feedback; decorative skin color stays subordinate to text and surfaces.
- Motion is limited to navigation and feedback, never operational status.
