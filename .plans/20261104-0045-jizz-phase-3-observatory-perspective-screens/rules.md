# Rules: JIZZ Phase 3 — Core Observatory & Perspective Screens

## UI & Antislop Guidelines
1. **UI Purity**: All components (`Button`, `Card`, `Badge`, `Input`) must come from `@moonwitness/ui`.
2. **No Fabricated Telemetry**: Avoid meaningless HUD copy, fake live radar rings, or simulated stats.
3. **No Biased Verdicts**: Present multiple viewpoints objectively without declaring winners.
