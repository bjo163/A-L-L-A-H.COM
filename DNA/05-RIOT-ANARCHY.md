# 05 — RIOT ANARCHY

## Break the Grid. Break the Rules.

**Parent identity:** Gen-Z grunge, manga, underground poster, and anti-design experiences  
**Core formula:** Japanese manga editorial × xerox punk × collage × brutalist poster  
**Emotional register:** Defiance, urgency, humor, raw energy, self-expression  
**Experience metaphor:** Navigating a living wall of underground posters

## Design thesis

RIOT ANARCHY treats the interface as a designed act of expression. It intentionally disrupts conventional alignment, scale, and surface polish. The disorder is authored and controlled: the user must still understand content, hierarchy, and actions.

This is not a broken interface. It is a loud visual system with deliberate rules.

## Composition grammar

- Oversized typography, cropped headlines, torn compositions, overlapping images, broken grids, and unexpected alignment.
- Use manga panels, comic frames, speech balloons, stamps, stickers, handwritten marks, and print artifacts.
- Compose as a zine spread, gig poster, underground magazine, or pasted wall.
- Allow controlled collision in decorative regions while reserving clean zones for forms, data, and primary actions.
- Use abrupt scale shifts and visual rhythm rather than repetitive card grids.
- Responsive layouts must recompose deliberately; do not merely shrink a poster until text becomes unreadable.

## Shape and material language

- Geometry: hard rectangles, jagged cutouts, tape strips, irregular crops, offset borders, torn silhouettes.
- Materials: xerox grain, halftone, ink bleed, photocopied paper, rough screen-print textures.
- Texture is a controlled layer; content and focus states must remain clear.
- Use original manga-like illustrations, not copied characters or proprietary panels.

## Color and typography direction

- Base: ink black, dirty white, photocopy grey.
- Signal accents: blood red, hazard yellow, electric blue used in deliberate combinations.
- Display: oversized condensed grotesk, bold display, cutout letterforms, handwritten accents.
- Body: readable sans-serif with consistent measure and line-height.
- Avoid using distressed type for long-form reading, labels, values, and forms.

## Navigation and interaction

- Navigation metaphor: poster strips, issue index, graphic labels, scene markers.
- Primary action: enter, submit, join, discover, or open an issue.
- Buttons may resemble stamps, taped labels, or printed commands, but must retain conventional interactive states and focus visibility.
- Dialogs may become full-screen comic spreads when the task benefits from it; preserve close, escape, and return behavior.
- Motion: fast cut, print reveal, kinetic headline, panel shift; never animate every element at once.

## Component interpretation

- Button → stamped command / graphic label.
- Card → cutout poster block / magazine feature.
- Navigation → vertical poster strip / issue index.
- Dialog → comic spread / fullscreen editorial layer.
- Tabs → high-contrast issue markers.
- Table → editorial data sheet with stable alignment.
- Form → deliberately ordered print form; labels and validation remain unmistakable.
- Empty state → one striking graphic gesture plus a clear next action.

## Hard exclusions

- No illegible primary text, unreadable distressed body copy, or hidden form labels.
- No uncontrolled overlap of essential controls.
- No imitation of named manga characters, existing album artwork, or identifiable poster designs.
- No indiscriminate glitch effect on every element.
- No hostile motion, inaccessible color-only signals, or hover-only instructions.

## Quality signature

A user should recognize RIOT ANARCHY through authored visual disruption, xerox and manga-print language, oversized graphic typography, and controlled rebellion.
